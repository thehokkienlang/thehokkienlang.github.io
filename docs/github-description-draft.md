# Tangliengim (TLI, 東寧音)

Source repository for [thehokkienlang.github.io](https://thehokkienlang.github.io/),
the home of **Tangliengim**, a Hangul-based writing system for **Hokkien**. The
Hangul here spells Hokkien, not Korean: readings follow TLI tones, tone sandhi and
Lomari romanisation.

**What's here**

- [Dictionary](https://thehokkienlang.github.io/dictionary/): about 2,900 entries with Hanri (漢字 / Hangul mixed script), Lomari, glosses, categories and audio.
- [Translator](https://thehokkienlang.github.io/translate/) and [Web IME Pad](https://thehokkienlang.github.io/ime/): type and convert Hokkien in the browser.
- Learning guides: introduction, romanisation, spelling, tone sandhi.
- [Songs](https://thehokkienlang.github.io/songs/): 81 songs with synced, followable lyrics, Hanri-Hangul, Lomari and translations, plus stories (The Egg) and literature.
- Site-wide search over dictionary, songs and pages.
- Desktop IME and local editors (dictionary, website, song) for maintainers.
- [TLI Keyboard for Android](android/README.md), a system keyboard that reuses the website's IME code.

The site is published in English at the root, with Traditional Chinese at `/zh-hant/`
and Simplified Chinese at `/zh-hans/`, all built by one GitHub Pages workflow.
