# Hokkien Tangliengim Root Site

This root GitHub Pages site redirects to the Hokkien Tangliengim Dictionary:

https://thehokkienlang.github.io/dictionary/

It also hosts the standalone web IME pad at:

https://thehokkienlang.github.io/ime/

The standalone IME loads its shared typing logic from the dictionary site so both pages use the same IME behavior.
