YouTube companion setup

Lyric timing

One-time setup in Microsoft Edge

  1. Open edge://extensions in Edge's address bar.
  2. Enable Developer mode, then choose Load unpacked.
  3. Select the folder below (the folder containing manifest.json):

    C:\Users\Asus\Documents\GitHub\thehokkienlang.github.io\desktop\youtube_companion

  4. Reload the lyric timing editor in that same Edge profile.
  5. Choose a song, then click Open YouTube window.
  6. Press Play in the YouTube window. Return to the editor to mark sentence starts and ends.

What it accesses

The extension runs on YouTube and the local lyric timing page only. It connects only the video window opened by the editor. It passes playback time, duration, and player state; it does not read your dictionary, repository files, passwords, or editor access token. No information is uploaded by the extension.

Timing pauses during YouTube advertisements. Keep both windows open and visible while timing. YouTube stays on its normal watch page with its normal controls and advertisements; embedding restrictions are not bypassed.

After updates

On edge://extensions, click Reload for TLI Lyric Timing Companion, then reload the editor and reopen its YouTube window.

Saving timings remains local. Commit and Push are still separate actions. This extension and setup page are not included in the public website build.
